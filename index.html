Memoria de proyectos culturales

Los proyectos terminan. Lo aprendido debería quedarse.

Cada proyecto cultural deja algo más que un resultado: quién trabajó con quién, qué sabía hacer cada equipo, qué materiales quedaron listos para usar de nuevo. SINC guarda eso como una red, para que la próxima iniciativa no arranque de cero.

  1. Explorá la red completa o un proyecto por vez.
  2. Preguntá quién puede ayudar o qué se puede reutilizar.
  3. Anticipá equipos y recursos para un proyecto que todavía no empezó.

Sugerencias del modelo

¿Con quién y con qué arrancar?

Para un proyecto planificado, un modelo de grafos entrenado en mundos ficticios propone vínculos que todavía no existen. Son hipótesis para conversar, no registros.

Para GraphSAGE: dos capas de agregación entre vecinos observados. Después se comparan los embeddings; la línea punteada no registra una colaboración.

Registrado Vínculos que ya figuran en la red.

Sugerido Candidatos que ordena el modelo. El puntaje sirve para comparar entre sí; no es una probabilidad.
